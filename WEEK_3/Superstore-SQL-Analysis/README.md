# Superstore SQL Analysis

## Objective

Analyze Superstore sales data using:

- Subqueries
- CTEs
- Window Functions

## Dataset

Sample Superstore Dataset

## Technologies

- MySQL Workbench
- SQL
- GitHub

## Business Queries Solved

1. Above Average Sales Orders
2. Highest Order Per Customer
3. Customer Sales Aggregation
4. Customer Ranking
5. Top Customers
6. Bottom Customers
7. Single Order Customers

## Insights

- A small number of customers contribute a large portion of total sales.
- Some customers placed only one order.
- Customer ranking helps identify high-value customers.
- Window functions simplify analytical reporting.
